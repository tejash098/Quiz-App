# Quiz App

A interactive Quiz Application built with React and Vite. This application allows users to take a quiz on Python programming concepts, tracking their score and providing results at the end.

## 🚀 Features

- **Interactive Menu**: Start the quiz from a welcoming menu screen.
- **Dynamic Quiz Interface**: Questions are displayed one by one with multiple-choice options.
- **Score Tracking**: Calculates and updates the score in real-time as you answer.
- **Results Screen**: Displays the final score upon completion.
- **Responsive Design**: Styled for a clean and user-friendly experience.

## 🛠️ Tech Stack

- **React**: Frontend library for building the user interface.
- **Vite**: Fast build tool and development server.
- **CSS**: Custom styling for components.

## 📂 Project Structure

```
src/
├── Components/
│   ├── End.jsx         # Component to display final score
│   ├── Menu.jsx        # Start menu component
│   ├── Quiz.jsx        # Main quiz question component
│   ├── QuizApp.css     # Styles for the application
│   ├── QuizApp.jsx     # Main container component managing state
│   └── QuizData.jsx    # Data file containing quiz questions
├── App.jsx             # Root component
└── main.jsx            # Entry point
```

## 📦 Installation & Setup

1.  **Clone the repository**

    ```bash
    git clone <repository-url>
    ```

2.  **Navigate to the project directory**

    ```bash
    cd Quiz-App
    ```

3.  **Install dependencies**

    ```bash
    npm install
    ```

4.  **Run the development server**
    ```bash
    npm run dev
    ```
